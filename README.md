# ML Engineer

**Category:** Specialisation Track - Nexora Institute of Computing

> **Status:** Scaffolded. See ROADMAP.md for the full route.

## Who this is for

Anyone who wants to build and ship machine learning systems in production, not just train models in notebooks.

## What you will be able to do

- Design and train ML models for real datasets
- Deploy models behind APIs at production scale
- Instrument and monitor ML systems
- Fine-tune and serve large language models
